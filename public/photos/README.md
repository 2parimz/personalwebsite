# Photos

Drop image files in this folder, then reference them from `src/content/site.ts`
as `/photos/your-file.jpg`.

Any entry left as `src: null` renders a tonal placeholder frame instead, so the
layout stays intact while you're still collecting images.

Suggested sizes (they get resized automatically by `next/image`):

- Portrait / cover shot — around 1200 × 1600
- Trip gallery — around 1600 on the long edge
